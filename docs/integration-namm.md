# Integration with NAMM

**NAMM** (Non-Anthropic Mathematics Mode) is a verification-first machine-native math discovery program. politic.bar does not embed NAMM code; it **consumes certified artifacts** where formal structure supports governance analytics.

---

## Repositories

| Program | Repo | Role |
|---------|------|------|
| **NAMM** | [errorlogy/namm-experiments](https://github.com/errorlogy/namm-experiments) | Protocol v2, experiments, `certificate.json` witnesses |
| **Errorlogy** | [errorlogy/errorlogy](https://github.com/errorlogy/errorlogy) | Governance ontology + MAS engine |
| **politic.bar** | this repo | Politifi assets, error cards, signal/noise streams |

Sibling lineage under Anthemium: see NAMM [`docs/ANTHEMIUM_NAMM_SYNERGY.md`](https://github.com/errorlogy/namm-experiments/blob/main/docs/ANTHEMIUM_NAMM_SYNERGY.md).

---

## Why NAMM matters for politic.bar

Governance analytics uses structures that may exceed compact human notation:

- Fuzzy membership over 381-mode universes
- α-propagation graphs and ACC contribution clusters
- T4D worldlines and CAT bifurcation hypotheses
- PNO regime classification and FPD trajectory forecasts

NAMM tests whether **machine-native formal artifacts** can certify properties of these structures before a compact human-readable projection exists. politic.bar treats NAMM outputs as **optional verification layer**, not as narrative authority.

## Integration points (v0.1 — documentation only)

| politic.bar artifact | NAMM analogue | Hook |
|---------------------|---------------|------|
| FPD forecast envelope | experiment certificate | Audit link: `causal_trace_ref` → `certificate.json` |
| α-graph invariant checks | formalized graph properties | NAMM experiment validates proposed invariant before production use |
| Mode-universe extensions (LΩ candidates) | novelty ladder + Protocol v2 gates | Taxonomy change proposals require falsifiable gate, not prompt edit |
| Politifi asset aggregation | meta-operator fixed points | Future: certified aggregation rules for multi-card components |

## Epistemic labels (shared with NAMM)

| Label | Meaning in politic.bar context |
|-------|--------------------------------|
| `OPERATIONAL` | Reproducible engine output or cited primary source |
| `COMPUTATIONAL_EVIDENCE` | NAMM certificate-backed claim |
| `PHILOSOPHICAL_INFERENCE` | Motivates research queue; does not satisfy publish gate |

Public error cards must **never** present philosophical inference or uncertified machine artifacts as legal or moral verdicts.
